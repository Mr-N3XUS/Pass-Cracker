## 📖 ABOUT

> **Pass-Cracker** is a minimal Python-based password recovery tool designed for educational purposes. It demonstrates basic password cracking techniques in a controlled environment. This project is intended to help understand the importance of strong passwords and security practices.

---

## ⚡ FEATURES

<br>

| 🔍 **Dictionary Attack** | 🐍 **Pure Python** | 📚 **Educational Tool** |
|:-----------------------:|:------------------:|:-----------------------:|
| Attempts to match passwords using a wordlist | No external dependencies | Learn about password security |

| 💻 **Command-Line Interface** | ⚡ **Fast Execution** | 🔒 **Controlled Environment** |
|:----------------------------:|:--------------------:|:------------------------------:|
| Simple and straightforward usage | Optimized for short passwords | Limited to 6 characters for safety |
